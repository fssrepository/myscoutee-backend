# MyScoutee 1.4.2 — four languages and smoother sign-in

[MSC-124](https://github.com/fssrepository/myscoutee-roadmap/issues/162) adds English, Hungarian, German and Spanish content throughout the application, admin interface and backend-owned catalogs.

## Changes

- Complete all four language catalogs, including help, guides, privacy/terms, articles, email and notification templates. Admin language selection includes German and Spanish. Compact interface labels retain the existing layout.
- Move device setup out of the sign-in and demo dialogs into the existing setup popup, reachable from a draggable floating button and a compact side-menu button beside the bell. Both share the same local missing-items counter; the new shortcut adds no HTTP request.
- Show entry guidance only when location setup is missing. That click opens the guide without opening Firebase or the demo selector, and closing the guide does not start authentication automatically.
- Show loading on the relevant location/notification control only after native permission acceptance. Replace the refresh action with individual control progress and clarify that the home-screen action adds an app shortcut.
- Prevent landing recovery from reloading during Firebase sign-in; retain the earlier removal of the redundant Firebase user reload. Continue the avatar loading ring across the lazy-menu handoff.
- Add migration `020-four-language-content` and its pinned JSON for existing installations and future Debian packages, preserving operator customizations and user content.
