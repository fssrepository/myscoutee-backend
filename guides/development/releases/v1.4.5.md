# MyScoutee 1.4.5 — loading, translations and WebP delivery

[MSC-126](https://github.com/fssrepository/myscoutee-roadmap/issues/164) delivers the prioritized performance batch, applicable template changes and the verified Netcup rollout.

## Changes

- Centralize cached HTTP/local constructors and feature loading groups. Main HTTP startup contains no local service/seed code; standalone startup contains no HTTP service code. Activity/assets/resource/admin/operator transitions each require one feature chunk in the inspected graph.
- Start with the preferred browser language, retain backend offline cache behavior and compare complete translation versions. HTTP startup does not request local EN/HU catalogs; a known version returns an empty data payload.
- Replace reviewed UI captions with semantic keys, retaining user content and canonical data values. Finish the article card actions/status/date captions through their existing owner. Both mobile setup popups use the existing fullscreen presentation. Roboto 400/500 are retained.
- Convert owned article/room media to direct WebP URLs through the numbered migration chain. Normal uploads retain their existing three WebP variants and stored originals.
- Preserve the intentional blocked/deleted frontend profiles and align only the two unchanged backend demo records. Main 024 pins 270 renames/four languages; 025 guards the two lifecycle corrections. Template 019 independently pins 52 applicable renames/two languages.
