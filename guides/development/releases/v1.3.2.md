# MyScoutee 1.3.2 — contextual guides and mobile ratings

Release date: 2026-09-30. Git tag: `v1.3.2` in the frontend (`myscoutee`)
and backend (`myscoutee-backend`) repositories.

## Changes

- Contextual EN/HU tours cover 45 surfaces and 963 guide fields, including
  public landing installation, demo and registration flows; authenticated menus,
  forms, event feedback, assets, groups and rating controls use the same model.
- Landing and authenticated flows share the draggable floating launcher.
  Landing dismissal lasts for that visit; existing explicit guide preferences
  remain respected. Nested guide/menu/popup dismissal follows overlay order.
- Desktop menus keep both floating launchers available, with the guide bulb
  above its tour shade. Mobile menus hide both launchers, including during a
  guide, without interrupting guide steps; closing the menu restores them.
  Notification layering remains unchanged.
- Mobile rating list and fullscreen structures stay mounted while switching.
  Cached photos are retained; fast scrolling defers image requests and suspends
  offscreen photo paint, badges, profile-eye controls and image indicators.
  Card frames and text remain in place. Floating controls stay anchored above
  the last row's profile-eye button.
- Write-side Event counters exclude ended events before the scheduled expiry
  pass marks them expired. The original batch expiry service remains unchanged;
  no separate Past job or rating-expiry rule is introduced.
- Migration010 installs compact guides and their indexed fields while retaining
  operator-authored/inactive revisions, user records and explicit preferences.
