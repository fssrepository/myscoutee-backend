ConceptMeaning
idThe caller-owned UUID sent in the request. It identifies the source-system record.
externalIdThe stable MyScoutee asset or event UUID returned for that request item.
OwnershipEvery created resource belongs only to the user who owns the integration token.
BatchOne request contains 1–1000 items. Further batches may be sent later.

2. Base URL and Authentication

Connect one external client

  1. Open the API popup from the lower-right corner of the profile identity header.
  2. Copy the full Base URL, including scheme, domain, and /api/integrations/v1 path.
  3. Generate an expiring client key. The complete token is shown only once.
  4. Configure one stable client UUID and call POST /connect.
HeaderValueRequired
AuthorizationBearer msc_…Yes
X-MyScoutee-Client-IdA stable UUID generated once by the external clientYes
Acceptapplication/jsonRecommended
Content-Typeapplication/json or multipart/form-dataYes for batch POSTs
One key, one client The first successful client UUID claims the key. Another client UUID cannot use it. A user may keep at most three active keys, and revocation blocks a key immediately.

4. ID Correlation and Retry Behaviour

{
  "items": [
    {
      "id": "1066b61b-c0ac-43d5-ab28-f588f5a162f6",
      "externalId": "55fe8563-f360-48cf-af0e-7cfb0404ee84",
      "result": "created",
      "error": null
    }
  ]
}

The caller stores the pair above. Repeating the same resource type and caller id for the same token owner returns the same externalId with result: "existing". It does not create or update a second resource.

Safe request retry If a client times out before receiving the response, it may repeat the POST with the same item IDs and recover the same MyScoutee IDs.

7. Optional Image Upload

Use the same POST /assets or POST /events URL with multipart/form-data.

PartContent typeContent
requestapplication/jsonThe complete batch object with its items array
Item UUID, for example 1066b61b-…image/jpeg, image/png, image/webp, or image/gifOne optional local image file for that item

Every file-part name must match an id in the JSON batch. At most one image may be attached to an item.

The server stores the original bytes and creates WebP variants whose maximum dimensions are 128 px, 640 px, and 1280 px. The resource points to the large variant.

No remote retrieval Do not send an image URL. The client and this API never retrieve an image from another server; either send the file bytes in this request or omit the image.

8. Change Callback

POST /watch registers one callback URL for the current token/client pair. It is a push notification mechanism, not a polling or general read endpoint. MyScoutee sends only event.changed for events managed by the token owner and asset.changed for assets owned by that user.

{
  "callbackUrl": "https://integration.example.test/hooks/myscoutee",
  "events": ["event.changed", "asset.changed"],
  "enabled": true
}

An empty or omitted events list selects both supported types. Disable the registration with {"enabled": false}. Revoking or expiring the client key also disables delivery.

Delivered message

{
  "deliveryId": "ad01bce2-70ac-4a60-8703-8f03bf105af6",
  "type": "event.changed",
  "occurredAt": "2026-09-19T22:28:46.947Z",
  "resource": {
    "id": "1066b61b-c0ac-43d5-ab28-f588f5a162f6",
    "externalId": "55fe8563-f360-48cf-af0e-7cfb0404ee84",
    "title": "Hotel evening",
    "status": "A",
    "change": {
      "kind": "participant",
      "status": "accepted",
      "role": "Member",
      "actionAt": "2026-09-19T22:28:46.919Z",
      "participant": {
        "name": "Peter",
        "age": 27,
        "gender": "man",
        "profileImage": "/media/public?key=…/large.webp"
      }
    }
  }
}

A normal participant Join and its later membership-state change trigger event.changed. The optional participant projection contains only name, age, gender, and first profile image; it contains no e-mail address or internal user ID. Resource snapshots may also carry event times and accepted/pending counts or asset type, quantity, and capacity.

9. Responses and Errors

HTTP/resultMeaning
200 / createdThe resource was created; externalId contains its MyScoutee UUID.
200 / existingThe caller id was already mapped; the same externalId is returned.
200 / rejectedThat item failed validation or creation; error contains a stable reason and externalId is null.
400The batch envelope or multipart relationship is invalid.
401The key is missing, invalid, expired, revoked, or claimed by another client UUID.

Common item errors include id_must_be_uuid, duplicate_id_in_batch, title_required, subtitle_required, valid_start_and_end_required, and the capacity-specific validation codes.

10. Java Client and CLI

./gradlew installDist

myscoutee-client configure \
  https://example.com/api/integrations/v1 \
  'msc_your_token'

myscoutee-client assets assets.json
myscoutee-client events events.json \
  1066b61b-c0ac-43d5-ab28-f588f5a162f6=event.webp
myscoutee-client watch https://integration.example.test/hooks/myscoutee
myscoutee-client unwatch
SDK methodUse
connect()Validate and claim the configured key.
createAssets(items)Send a JSON-only asset batch.
createAssets(items, images)Send assets and a map from item UUID to local image path.
createEvents(items)Send a JSON-only event batch.
createEvents(items, images)Send events and optional local images.
watch(callbackUrl, events)Register the callback and selected event types for this client.
unwatch()Disable the current client's callback.

The CLI stores the Base URL, token, and stable client UUID in ~/.myscoutee/client.properties. The token is masked by show-config.

11. Security and Operational Rules

  • Use HTTPS outside localhost development.
  • Keep the complete key secret and use a distinct key for every connected client.
  • Revoke a lost or retired key from the profile popup immediately.
  • Retain both id and externalId in the external system.
  • Split imports into batches of no more than 1000 items.
  • Do not infer access to another user's records: the token fixes the resource owner.
  • Do not include participant personal data in asset or event create requests.
  • Return a fast 2xx from the callback and process asynchronously; deduplicate every delivery ID.
  • Expose callback endpoints over public HTTPS in production and reject unexpected payload types.
