# World lapok

- [real](real/README.md): 21 jelenvárosi A–B–C oldal, 4K 2×2, értékelőkártyás járókelőkkel.
- [memories](memories/README.md): 30 emléki/klinikai és T01 A–B–C oldal, 4K 2×2, kártya nélküli emlékszereplőkkel.
- [maps](maps/): hét opcionális térterv.

Több world-oldal használható egy videóban. A lapok külön nézetei nem videóvágások. A részletes átalakulásokat a [morph-könyvtár](../morphs/README.md) tartalmazza.
