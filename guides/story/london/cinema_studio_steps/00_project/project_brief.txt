# MyScoutee - THE PATH BETWEEN PEOPLE

- MYSCOUTEE — THE PATH BETWEEN PEOPLE follows one continuous walk through an impossible London–Budapest city, where fragments of a life appear inside windows, vehicles and wet reflections. Travel, work, relationships and encounters with institutions collide out of order, while people continuously reduce one another to visible scores. Beneath the systems, classifications and absurdities, the film keeps returning to the same question: what remains of a person when the record can never contain the whole story?

## ✨ Context

MyScoutee is a real AI-assisted social software project with public presence on YouTube, LinkedIn, Instagram and Facebook. A large source archive became a two-volume Amazon book in roughly two days. ChatGPT GPT-5.6 Sol, Pro 5× High Reasoning then artistically transformed the two books into one canonical cinematic master prompt in roughly one additional day. Only a few weeks before this production, the creator had no practical knowledge of AI video generation. Pre-production was validated in Google Flow with Nano Banana 2, Nano Banana Pro and Gemini Omni Flash.

## 🎭 Narrative

Seven linked blocks move from social memory through travel, work, procedure and classification toward brief human counter-memories and a final clinical reveal. Memory order is emotional rather than chronological; the film preserves awkwardness, kindness and black humour without turning people into heroes or villains.

## 🎨 Visuals

Photorealistic European feature-film realism: rainy blue hour, wet stone, real glass, London geometry fused with explicit Budapest architecture, yellow trams and Hungarian signage. Memories move inside reflections; no fantasy glow, game-engine look or obvious sci-fi HUD.

## 🎬 Production

Video and narration are generated in Higgsfield. The full narration will be generated as one recording and added to the assembled 3:20 film. GPT-6 Astra will use FFmpeg locally to join the clips and add narration, then the finished film will be uploaded to Higgsfield for publication. This workflow is being tested.

## 🚀 Status

- MASTER PROMPT READY: v2.2.57 — 488,623 bytes (~477 KiB), 6,425 lines, ~68,700 words.
- IMPORT ELEMENTS: 128 KiB Markdown limit; clean import = 48 canonical Elements: 31 Characters + 16 Locations + 1 Prop.
- AUDIO LIMITATION: Videos can be saved as reusable Elements; audio files cannot, despite being accepted as generation references.
- **NARRATION REMOVAL TEST:** Generated narration was mixed with the video's background audio. Our removal attempt also damaged the background and was not usable. We will generate the film clips without narration and add the complete narration recording afterwards.
- **EMBEDDED SUBTITLE GAP:** We uploaded an MP4 with an embedded subtitle track marked as default, intended to display “TEST PUBLICATION — NOT THE FINAL FILM” without changing the video pixels. The Higgsfield player did not show the label. Uploading the subtitles inside the video file was therefore insufficient to make this test notice visible.
- **CONTINUATION CONTEXT GAP:** We tried to generate the next four seconds of an existing shot. A video reference produced a revised shot rather than the requested continuation; using its last frame supplied the starting composition but not the preceding camera movement, walking rhythm or sound. We still need a continuation route that uses this history. This gap is separate from the image-position errors measured below.
- **END-FRAME EXPORT BUG:** We exported the first clip’s last frame in Higgsfield to start the next clip. Comparing the downloaded image against all 97 source frames showed that it matched frame 94, not the actual final frame 96 (zero-based, 24 fps): the continuation reference was already two frames, or 83 ms, behind. The exported image preserved frame 94’s geometry. Astra will extract and verify the actual final frame locally with FFmpeg.
- **CONTINUATION ALIGNMENT BUG:** We supplied that exported image as an Element reference and asked the next clip to begin from its composition. The generated opening nevertheless displaced image content approximately 8 px left and 8 px up at 854 × 480, with a small scale change, producing a visible jump at the join. This second mismatch was measured against the supplied image itself, so the early export does not explain it. Improving the join required gradual spatial warping across 30 frames, frame cuts, audio retiming and re-encoding; simple lossless concatenation was insufficient.
- LAST-FRAME GAP: Extracted end frames appear as temporary references, with no clear way to find them in Assets or link them to the source video’s Element for reliable reuse.
- **EXTEND REFERENCE GAP:** In our workflow, the Extend interface is a reduced version of the Cinema Studio composer: it lacks the automatic Element reference resolution available in the main composer, requiring manual reference selection for continuation.
- PROMPT LENGTH: 15.000 characters limit
- ELEMENT MEDIA GAP: MCP can upload media and create Elements, but cannot attach / replace / upsert image media on an existing imported Element.
- PROJECT-STATE GAP: Elements are workspace-global; MCP cannot manage Scene-folder membership or reliably transfer existing assets into the contest project. `Move to` removed project visibility in testing.
- **PROJECT REMOVAL GAP:** In our testing, deleting Elements from a project leaves them available outside that project. The UI should clearly distinguish removing an Element from a project from deleting it globally.
- **GENERATION DESTINATION GAP:** Generating outside a project created a new project automatically instead of asking where to place the output. The interface does not clearly distinguish working inside a project from working outside one; show the active project or global context and make the destination explicit before generation.
- **SCENE EDITOR GAP:** Seedance already generates music and ambience, but Cinema Studio needs a simple timeline to join clips and add separately editable narration over that soundtrack. The minimal Extend interface leaves basic assembly to downloading, external editing and re-uploading. With Supercomputer already available, this feels like a missing integration. Finishing an AI film should not require professional editing software—DaVinci Resolve cannot run on my machine because of GPU limitations.
- **SUPERCOMPUTER INTEGRATION GAP:** We have not seen deeper project integration than an external AI assistant connected through MCP. The MCP limitations documented above would still block our workflow. Without direct asset management, clip assembly and separate narration controls, the added value over our existing OpenAI subscription is unclear, while chat consumes additional Higgsfield credits.
