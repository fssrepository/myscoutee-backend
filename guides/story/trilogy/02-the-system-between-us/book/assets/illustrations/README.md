# Part II book illustrations

These are provisional review assets, not locked character references.

The original generated `*.png` files retain their complete canvases. Their
uniform brown side fields are part of those canvases rather than part of the
book layout. The matching `*-portrait.png` files are mechanically trimmed print
derivatives: no person, pose or scene content was regenerated or rewritten.
`illustrations.json` points the book to these narrow derivatives through the
`portrait-right` placement so prose wraps only around the visible portrait.

The current single forensic-expert study remains excluded from the manuscript.
The reviewed story requires two distinct experts in the same examination, so a
new two-person scene and separate identity references must replace it after the
text and character map are approved.

When a character is regenerated after review, keep the full source image and
derive the book crop from that approved source. Do not enlarge a narrow portrait
by restoring coloured side padding.
