## Review order

Review the manuscript first. Every requested correction should be made in the
chronology and manuscript before it reaches the film script, storyboard and
prompt pack. Do not repair a factual problem only inside a visual prompt.

The next approval gates are:

| Gate | Decision | Credit use |
| --- | --- | --- |
| A | written-source chronology accepted | none |
| B | private audio transcribed locally and checked | none apart from optional local tooling |
| C | public/private boundary and legal wording reviewed | none |
| D | book review draft accepted | none |
| E | Part I-style review PDF built and visually inspected | local CPU only |
| F | 03:00 narration and shot order accepted | none |
| G | checkpoint stills generated and approved | still-image credits only |
| H | eight-second scene-hold slideshow assembled | local CPU only |
| I | Flow/OpenArt motion tests begin | video credits |
| J | narration, one continuous score and sound design | only after picture timing is stable |

## Truth layers

Every scene must identify which layer it belongs to:

- **D — documentary record:** date, filing, official decision, public law or
  verifiable public event;
- **M — memoir:** what the Founder remembers feeling, seeing or saying;
- **A — attributed account:** a remark or reaction recorded in one of the
  Founder's submissions but not yet independently verified;
- **C — context:** later public developments placed beside the personal story
  without claiming they prove the Founder's earlier legal interpretation.

The film may compress time but may not merge those layers into one claim.

## Production hold

Do not yet:

- generate character sheets or scene images;
- assemble the slideshow;
- upload private audio or primary legal documents to a cloud model;
- generate Flow/OpenArt clips;
- lock, hash or publish the book;
- imply an acquittal, conviction, clinical conclusion or final political result
  that has not occurred.

The planned visual continuity is already documented so no disposable images are
needed while the text is still changing.
