# Part II research

This directory separates source control from memoir prose.

- [SOURCE_INVENTORY.md](SOURCE_INVENTORY.md) records the reviewed primary
  package and unresolved media.
- [SOURCE_COVERAGE_REPORT.md](SOURCE_COVERAGE_REPORT.md) distinguishes archive
  discovery, technical access, substantive use, deliberate exclusions and
  unresolved claims.
- [CHRONOLOGY.md](CHRONOLOGY.md) holds the event sequence and confidence gates.
- [PUBLICATION_BOUNDARY.md](PUBLICATION_BOUNDARY.md) defines what must be
  anonymized, attributed, generalized or withheld.
- [EXTERNAL_CONTEXT.md](EXTERNAL_CONTEXT.md) records current public sources for
  KATA, protest history, judicial change, migration and foreign-currency-loan
  context.
- [ARCHIVE_MAP.md](ARCHIVE_MAP.md) explains the 4.1 GB backup without copying it.
- [REVIEW_LEDGER.md](REVIEW_LEDGER.md) prioritizes source families and prevents
  duplicate volume from masquerading as corroboration.
- [SCENE_CANDIDATES.md](SCENE_CANDIDATES.md) records cinematic material without
  forcing every striking detail into the three-minute film.
- [ROLE_GLOSSARY.md](ROLE_GLOSSARY.md) keeps private actors anonymous and the
  three-judge sequence distinct.
- [TONE_AND_IRONY_LEDGER.md](TONE_AND_IRONY_LEDGER.md) separates documented
  authored sarcasm, remembered human reactions and later literary compression.

The private source package remains outside the repository. It is not copied
into this public-facing story tree.
