# Part II frame sources

This directory keeps the durable editable layouts for the Part II opening and
ending frames. Canonical delivery frames remain under `assets/frames/`.

- `M2_P00.svg` is the layout source for `assets/frames/M2_P00.png`.
- `M2_E01.svg` is the layout source for `assets/frames/M2_E01.png`.

SVG references are repository-relative and therefore expect reconstruction
tools to be invoked from the repository root.
