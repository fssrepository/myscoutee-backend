# Part II published artifacts

This flat directory is reserved for the approved public outputs only:

- versioned English PDF book;
- PDF SHA-256 checksum;
- publication metadata;
- final public film master.

Drafts, source evidence, prompts, checkpoints and platform tests do not belong
here. Public edition `1.0.0` consists of the versioned English PDF, its SHA-256
checksum and publication manifest. On 9 August 2026, before the synchronized
two-film production handoff, the Founder explicitly authorized replacement of
the current `1.0.0` artifact without changing its edition number. The
replacement receives a new checksum and manifest; Git history preserves the
earlier bytes. Later post-handoff corrections require a new version.
