# Part II published artifacts

This flat directory is reserved for the approved public outputs only:

- versioned English PDF book;
- PDF SHA-256 checksum;
- publication metadata;
- final public film master.

Drafts, source evidence, prompts, checkpoints and platform tests do not belong
here. Public edition `1.0.0` consists of the versioned English PDF, its SHA-256
checksum and publication manifest. Its first public release date is 12 August
2026. Corrections completed before that release remain within `1.0.0`; Git
history preserves the preceding working builds. Later released corrections
require a new version.
