# Part II published artifacts

This flat directory is reserved for the approved public outputs only:

- versioned English and Hungarian PDF books;
- matching reflowable EPUB 3 editions, each with an internal cover rendered
  from its verified public PDF;
- a format-specific SHA-256 checksum and publication manifest for every
  released artifact;
- final public film master.

Drafts, source evidence, prompts, checkpoints and platform tests do not belong
here. Public edition `1.0.0` consists of the versioned English and Hungarian PDF
and EPUB books, their SHA-256 checksums and publication manifests. Its first
public release date is 20 August 2026. Corrections completed before that release
remain within `1.0.0`; Git history preserves the preceding working builds.
Later released corrections require a new version. The EPUB source artifacts
contain no DRM. Store-level DRM remains a separate publishing-platform choice
and does not change the copyright or reuse terms.
