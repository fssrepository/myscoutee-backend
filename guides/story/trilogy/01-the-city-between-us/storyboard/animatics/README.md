# Storyboard animatics

This directory contains timing and continuity previews built from storyboard
frames. These files are planning artifacts, not public film masters.

The next `myscoutee-part-i-8s-endpoints-720x1280.mp4` will be the canonical
still-only production review. It will hold CP00, CP01 and every subsequent exact
9:16 checkpoint through CP22 for a complete eight seconds at 00:00, 00:08,
00:16 and so on, followed by the four-second CP23 end plate. Its inspection
runtime is 03:08.000 at 24 fps; the finished moving film remains 03:00.000.

The superseded three-second review and the earlier 03:00 four-second-split
endpoint review are not retained. Do not rebuild this file until the book and
prompt review is closed and the approved checkpoint set exists.
