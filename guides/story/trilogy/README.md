# Trilogy parts

This directory contains the three independent narrative packages:

- [`01-the-city-between-us/`](01-the-city-between-us/overview/README.md)
- [`02-the-system-between-us/`](02-the-system-between-us/overview/README.md)
- [`03-unassigned/`](03-unassigned/overview/README.md)

Each part root contains directories only. Shared product truth, production
planning, platform workflows and series metadata belong in
the sibling [`shared/`](../shared/README.md) package.
