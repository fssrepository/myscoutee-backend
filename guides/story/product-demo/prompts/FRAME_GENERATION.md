# Product-demo checkpoint generation briefs

These eight frames are original assets owned by this package. Seven were created
with the built-in image-generation workflow and CP02 was recovered from the
accepted earlier render endpoint, then all were normalized to `720×1280` by
`scripts/build_brand_frames.py`. The resulting production package does not
reference a trilogy asset.

are deliberately different from the later six-user group. No text, logo, app
UI, public rating, forced pair, child, duplicate identity, server,
administrator, operator or watermark.
