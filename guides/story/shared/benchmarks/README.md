# Shared benchmark system

- `prompts/` contains the locked cross-model comparison prompts.
- `assets/` contains approved controls used to judge comparable outputs.
- `tracking/` contains reusable CSV score schemas and recorded runs.

The current video stress test uses Volume I's CP18→CP19 scene because it exposes
identity, six-person counting, anatomy, acting, endpoint fidelity and style in
one potentially final shot. Future volumes reuse the method and logs; they do
not inherit Volume I's characters as narrative canon.
