# Shared trilogy system

This package contains material intentionally reused across MyScoutee story
parts. It must not contain a part's manuscript, private evidence, shot
manifest, final render or production handoff.

## Packages

- [`benchmarks/`](benchmarks/README.md): stable image/video comparison prompts,
  control assets and score logs;
- [`metadata/`](metadata/README.md): trilogy-level machine-readable metadata;
- [`production/`](production/README.md): cross-part planning and platform
  workflows;
- [`research/`](research/README.md): shared product truth, research and claim
  boundaries.

Part I remains the concrete working example in several shared documents. A
link to a Part I checkpoint or prompt is an example/input reference, not a
transfer of story ownership into this package.
