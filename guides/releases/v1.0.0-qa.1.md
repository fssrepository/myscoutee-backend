## MyScoutee 1.0.0 QA Preview 1

Early Debian QA prerelease for amd64. This build is intended for installation
and integration testing and is not production-ready.

## Qualification performed

- Debian installation and same-version reinstall tested on VMware.
- Backend, frontend, MongoDB, Redis, MinIO, nginx and demo Registry startup verified.
- Deployment verifier: 10 passed, 0 failed, 3 skipped because the verification used a custom HTTPS tunnel port.
- Clean demo reset and generated MinIO demo images verified.
- Existing production database content remained unchanged during reinstall.

## Manual QA status — 2026-08-15

- Total test cases: 189
- Done: 53
- Pending: 20
- Not started: 116
- Failed: 0
- Core: 53 / 133 done (40%); 80 remain open
- External/operator/payment/deployment: 56 remain open

No case currently remains in terminal Failed state, but 136 cases are not yet closed.

## Known limitations

- Manual QA is incomplete.
- Firebase operator configuration and real Firebase login are not fully qualified.
- Payment/provider integrations and external Registry/operator workflows are not qualified.
- No production domain or production TLS qualification has been performed.
- The Debian package is currently unsigned. The attached SHA-256 files verify integrity, not publisher authenticity.
- amd64 only.
