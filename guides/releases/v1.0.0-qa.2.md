## MyScoutee 1.0.0 QA Preview 2

Early Debian QA prerelease for amd64. This build is intended for installation
and integration testing and is not production-ready.

## Qualification performed

- Local Debian candidate built once and installed as a same-version `1.0.0` refresh on VMware.
- Backend, frontend, MongoDB, Redis, MinIO, nginx, Explore Registry and Explore payment simulator started healthy.
- Installed package qualification passed.
- External deployment verifier passed: 13 passed, 0 failed, 0 skipped over canonical localhost ports 80/443.
- Isolated read-only browser smoke passed: main document 200, Angular rendered, version metadata matched `1.0.0`, 0 uncaught exceptions and 0 unexpected browser errors.
- No Nginx, deployment URL or noncanonical port override was used.

These are measured local-candidate results, not final tagged-release evidence.
Release tooling and documentation changed afterward, so the artifacts attached
to `v1.0.0-qa.2` must be rebuilt and requalified after pair QA selects the
commit. The standalone Registry remains unchanged at commit `0a0d366`, already
tagged `v1.0.0-qa.1`; the package's internal Explore Registry is a separate
managed image.
