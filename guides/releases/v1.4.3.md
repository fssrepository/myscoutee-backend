# MyScoutee 1.4.3 — demo access and browser permissions

[MSC-124](https://github.com/fssrepository/myscoutee-roadmap/issues/162) fixes demo entry and location setup in Instagram/Facebook browsers. This corrected **1.4.3 replaces the earlier 1.4.3**: both Git tags, GHCR aliases and release assets are updated together.

## Changes

- **Explore opens the demo selector directly**, without the visitor's location guide, browser location permission or country restriction. Demo profiles use their own supported sample coordinates in browser-local and HTTP mode, including group profiles, administrators and the operator. Background tracking and cached visitor-login coordinates no longer replace a demo profile's location.
- **Sign in opens the existing permissions popup directly when location setup is missing.** The optional guide stays available through its existing launcher. Notifications and the home-screen icon remain optional.
- **Open in external browser** is a dark, high-contrast button with emphasized explanatory text. Android handoff retains the current page, campaign query and fragment. The short English, Hungarian, German and Spanish notices explain why location is needed and that Facebook/Instagram may block access.
- Correct the landing guides' misleading “all optional” wording and retain the setup badge fix: unavailable notification/install actions do not inflate its count.
