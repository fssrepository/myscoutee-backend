# MyScoutee 1.3.1 — frontend patch

Release date: 2026-09-29. Git tag: `v1.3.1` on the frontend (`myscoutee`)
and backend (`myscoutee-backend`) repositories.

## Scope

Only frontend runtime code changed since `v1.3.0`. The backend repository changes
are its frontend submodule reference, QA launcher and documentation. Backend
runtime, API contracts, nginx configuration, deployment scripts and seeds are
unchanged. Registry, payment simulator, Java client, admin client and MCP remain
at their existing `v1.3.0` commits and are not retagged or rebuilt.

- Setup opens immediately and loads permission state within the popup, reusing
  the existing deployment configuration.
- Stacked full-height popups match the home frame, retain their underlying
  content and avatar, and contain SmartList rows within their bounds.
- Side-menu popup actions close the side menu; Share is in Settings.
- Guides use a repeatable floating launcher above notifications instead of
  opening automatically and remembering an acknowledgement. The standard popup
  X closes the guide. Long-press drag and dismissal are independent of the
  global guide switch. Desktop popup opening preserves launcher position.

## Artifact and deployment boundary

The production HTTP frontend was built with `build:prod` from frontend commit
`9b350bf021629b6179bc799ed0510703cc8538fa`. Build ID:
`9b350bf02162-20260928233206`.

Only `ghcr.io/fssrepository/myscoutee-nginx:1.3.1` is published. Its immutable
reference is:

```text
ghcr.io/fssrepository/myscoutee-nginx@sha256:dfdf6cd50a72b635a71b5a1ae4f6d32d653c0f3cd3455ac05e2ff4ea200056cf
```

This image explicitly declares compatibility with installed package `1.3.0`.
The nginx base and all other service images are retained. No DEB, signed package,
automatic-update catalog, GitHub Pages build or data migration is produced.
Netcup's installed Debian package remains `1.3.0`; its frontend reports `1.3.1`.

Deployment uses the existing digest-pinned `install-temporary-image.sh` helper.
It updates only `NGINX_PRODUCTION_IMAGE`, retains the existing Compose overlays,
recreates only nginx, and retains the previous image selection for explicit
rollback. It does not reset production or Explore data.
