# Rough storyboard frames

These 9:16 concept frames support the three-second-per-shot storyboard preview.
They are planning images, not approved production plates.

- `S01`–`S22` use a fictional Founder identity placeholder generated for this
  rough; they do not depict or replace the real founder reference.
- `S23` is assembled deterministically from the repository brand asset and
  editable text; it is not AI-generated.
- Labels and action summaries are added by the slideshow build script, not by
  the image model.
- Keep only the selected rough frame for each shot. Do not commit discarded
  variants or rejected render exports.
