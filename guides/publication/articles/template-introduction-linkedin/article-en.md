# MyScoutee Template: a serious foundation for your next application

A new application needs more than its first screen. It needs identity, permissions, communication, administration—and a way to install, update and recover it.

**MyScoutee Template 1.4.0** brings those foundations together, extracted from MyScoutee and stripped of its product-specific business domains.

The sample application is deliberately small. The foundation underneath it is substantial:

- **Application essentials:** member, administrator and operator interfaces; profiles, consent, notifications and contextual guides.
- **Reusable interaction:** shared Angular components, SmartList calendar/list views, chat and calls, plus API and MCP integration.
- **An operational starting point:** a Java backend supporting both monolithic and microservices deployments, Debian installation, signed updates, backup and recovery.

Browser-local mode lets you explore the interface with sample data. Connect an HTTP backend for live communication. The developer and operator guide explains the architecture, extension points and deployment paths; the components catalogue is available as a separate PDF.

This is a heavyweight starting point for projects that need more than a landing page: internal platforms, collaboration tools and applications with distinct user and operator responsibilities. Bring your own domain, product name and branding, and build on the existing foundations.
