# Project statistics

[Measurements](measurements.json) retain the recorded token usage, active AI
intervals and estimated API-equivalent cost. [Method](METHOD.md) defines the
measurement boundaries and limitations; these are not human timesheets or invoices.

The roadmap repository owns the full project/issue history and its authoritative
measurement updates. Application guides do not keep another project-restore
script, issue export or backup ledger.

[Film production](film-production/README.md) retains the separately frozen story/film
effort and image-adherence measurements, with their own method and cutoff.
