Tools
=====

The tools folder is split by purpose:

- `install/` builds, uploads, installs, and smoke tests the Debian package using a local ignored env file.
- `docker/` contains local Docker build/reload helpers.
- `misc/` contains unrelated local helper scripts.

Install docs:

```text

```

